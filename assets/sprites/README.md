## Sprite Sources
Obtain sprites from:
- https://www.spriters-resource.com/game_boy_advance/fireemblemthesacredstones/

## Sprite Requirements
- PNG format with transparency
- Include both idle and battle sprites if available
- Organize by character state (idle, moving, attacking)
- Maintain original pixel art quality

## Usage
These sprites will be displayed in:
- Unit panel showing active units
- Character selection screens
- Battle preview animations
- Chronicle story sections
